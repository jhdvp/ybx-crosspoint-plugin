## Матрица возможностей

| Область | Реализация | Оговорки |
| --- | --- | --- |
| QR / device-code авторизация | Есть | При потере `token.json` требуется повторная привязка |
| Яндекс Книги: четыре полки и поиск | Есть | Нужна подключённая библиотека в YBX |
| WB Книги: полка и EPUB | Есть | Не все книги источника доступны к выгрузке |
| ЛитРес в собственных полках | Нет | Приобретённые EPUB могут быть доступны через OPDS отдельно |
| Скачивание EPUB | Есть | Права и ограничения поставщика действуют |
| Читательский веб-профиль | Есть | Минуты, серия, календарь, цель года, достижения |
| Экран сна YBX | Есть | Пользователь включает добровольно, картинка требует поддержки firmware |
| Сохранение настройки сна при обновлении | Есть | При полной замене папки плагина локальные данные могут быть потеряны |
| KOSync через плагин | Есть | Отдельный `kosync_`, сервер `http://sync.ybx.app`; HTTP не шифруется |
| Ручной KOSync аккаунта | Есть | Независимые логин и пароль из кабинета |
| Двусторонний KOSync на настоящем X4 Pro | **Не подтверждено** | Нужен реальный GET / Apply Remote и сопоставление EPUB |
| Экспорт vCodex-статистики | Есть | Процедура импорта определяется прошивкой; осторожно с существующими данными |
| Поддержка InkHome | **Исследуется** | Пока не рекомендуется импортировать YBX-статистику в живые данные InkHome |

## Что исправлено в 1.6.12

- Отзыв старых ключей после *успешного* обмена позицией, а не в момент ошибки или проверки логина.
- Переходный период 15 минут при успешном использовании нового ключа.
- Сохранение обработчика `sleep.enter` при обновлении внутри веб-панели и сохранение пользовательского выбора при внешней замене релизных файлов, если настройка уцелела.
- Безопасное снятие старой карточки и защита `sleep-legacy.bmp` от перезаписи.

**Проверка релиза:** целевые тесты plugin.js и KOSync, сверка runtime payload с серверной раздачей, CI и production smoke. Физический X4 Pro этими проверками не заменяется.

## InkHome — что имеет смысл интегрировать

[InkHome](https://github.com/mohitagw15856/inkhome) — самостоятельный форк CrossPoint (MIT), а не обычный SD-плагин. Его возможности нельзя обещать для stock CrossPoint.

| Возможность | Перспектива для YBX |
| --- | --- |
| `Custom + stats`, `Cover + stats` | Для собственной YBX-прошивки: независимый overlay без замены пользовательских обоев |
| `/.crosspoint/reading_stats.json`, formatVersion 6 | Можно обмениваться статистикой после определения безопасного merge/import протокола |
| Автоскриншоты из симулятора | Использовать как пример для UI-тестов YBX X3/X4 |
| `/Pushed Images`, `.xth/.xtg` | Для будущей собственной прошивки, не для обычного JS-плагина |
| Нативный Apps SDK | Только при отдельной прошивке, а не в публичном ZIP |

### Риск потери данных

В InkHome `ReadingStatsTracker::importFrom()` заменяет текущую структуру статистики загруженным файлом; YBX 1.6.12 при экспорте также предлагает записать `/.crosspoint/reading_stats.json`. **Если согласиться на перезапись, накопленная на ридере статистика может быть утрачена.** До безопасного импорта следует использовать отдельный staging-файл, гарантированную резервную копию и дедуплицирующее объединение по книге/сессии.

В InkHome есть собственные режимы сна с числовыми кодами 8, 10 и другими. Переключатель YBX рассчитан на стандартные коды 2/3/4 и может заменить пользовательский режим InkHome. Нужна проверка firmware-capabilities, а не только версии.

InkHome по собственному чек-листу ещё не протестирован на физике.

## Roadmap

1. **Приоритет 1:** безопасный экспорт статистики (не перезаписывать живой `reading_stats.json`), определить обработку vCodex/InkHome и тестировать импорт с дубликатами.
2. **Приоритет 1:** исключить вмешательство кнопки YBX в нестандартные режимы сна сторонних прошивок; определять режимы по возможностям.
3. **Приоритет 2:** реальный двусторонний KOSync на X4 Pro с CrossPoint 2.0, включая разные EPUB одной книги.
4. **Приоритет 2:** подтвердить сохранение учётных данных при обновлении через Plugin Hub.
5. **Приоритет 3:** симуляторные снимки меню и кнопочной навигации X3/X4 как воспроизводимый тестовый артефакт.
6. **Отдельный проект:** YBX Reader на базе CrossPoint с возможностями нативных приложений и накладываемой статистики.

Результаты аппаратного теста можно прикладывать к [issue](https://github.com/jhdvp/ybx-crosspoint-plugin/issues).
