# YBX для CrossPoint

Плагин YBX для ридеров на прошивке CrossPoint (Xteink X4, X3, X4 Pro и др.):
библиотеки **Яндекс Книг** и **WB Книг** из подключённых аккаунтов YBX.
Литрес пока не подключён к скачиванию через этот плагин.

## Возможности

- **Авторизация по QR-коду (RFC 8628)**: вывод кода и QR-ссылки прямо на e-ink экран для быстрой привязки через смартфон без ручного ввода паролей.
- **Полки каталога**: просмотр списков «Читаю», «Хочу прочитать», «Прочитано» и «Все книги» Яндекса, а также отдельного раздела «WB Книги».
- **Поиск**: поиск по каталогу с экранной клавиатуры ридера.
- **Загрузка книг**: прямое скачивание EPUB в папку `/books/ybx/` на карте памяти с автоматической записью метаданных в sidecar-файл (`.meta.json`).
- **Мгновенное обновление библиотеки**: новые книги сразу видны в Библиотеке ридера без перезагрузки (CrossPoint 2.0.0+).
- **События чтения**: аналитика открытия, выхода, сессий, загрузок и сна. Эти события не записывают позицию чтения в подключённые магазины.
- **Позиция чтения**: отдельно настраиваемый встроенный KOSync; плагин не настраивает его автоматически.

> **Токен и обновления.** После входа токен лежит в папке плагина (`token.json`).
> Обновление через Plugin Hub заменяет папку, поэтому после такого обновления
> привязку нужно повторить. Это компромисс: firmware не создаёт каталог
> `plugin-data`, и токен в нём не сохранялся на чистой SD.

## Установка

1. Скопируйте папку `ybx` на MicroSD карту в директорию `/plugins/ybx/` (или `/.crosspoint/plugins/ybx/`).
2. Включите плагины в настройках ридера: **Настройки → Подключения → Плагины → Включено** (или **Settings → Connectivity → Plugins**).
3. На главном экране выберите пункт **Плагины → YBX**.

## Авторизация

1. При первом запуске плагин отобразит код устройства (например, `WDJB-MJHT`) и QR-код.
2. Отсканируйте QR-код камерой смартфона — откроется страница `https://my.ybx.app/pair?code=...`.
3. Войдите в свой Яндекс ID и нажмите **Подключить**.
4. Ридер получит отдельный токен плагина `cp_…` на 90 дней и откроет список полок. Токен сохраняется в `/plugins/ybx/token.json` (либо в каталоге установки) и теряется при обновлении через Plugin Hub — см. примечание выше. Автоматического обновления нет: после истечения срока повторите привязку. Этот токен работает только в `/api/v1/crosspoint/*`, не заменяет ключ ридера или пароль KOSync.

## Профиль: статистика и достижения

Страница **Settings → YBX** повторяет экран профиля читалки YBX:

- сегодня, серия дней, минуты за неделю, книги за год;
- прогресс цели года и полоса последних семи дней;
- «Продолжить чтение» с процентом по книге;
- полученные и ближайшие достижения Яндекс Книг.

Данные приходят с device-scoped эндпоинтов YBX (`/api/v1/crosspoint/reading/*`,
`/achievements`) по токену плагина и не покидают устройство.

## Экран сна со статистикой

Плагин обновляет **кастомный экран сна** перед засыпанием:

- `sleep.enter` с `"connect": true` поднимает Wi-Fi (заряд ≥20%, сохранённая
  сеть, проба до 10 с) и кладёт серверный 1-bit BMP в `/sleep.bmp`;
- карточка: минуты за сегодня, серия, неделя, цель года;
- **Settings → YBX → Экран сна** — переключатель: «Включать» ставит
  `sleepScreen = CUSTOM` («Свой»), «Выключить» — `COVER` («Обложка»); режим
  подписан словами.
- «Обложка + Свой» тоже рисует карточку, когда сон не из книги (или у книги нет
  обложки) — отсюда «выключил, а она приходит»; плагин называет режим и
  подсказывает, что переключатель его выключит.

## Выгрузка облачной статистики в ридер (vCodex)

Кнопка **«Выгрузить статистику (vCodex)»** в **Settings → YBX** кладёт облачную
статистику YBX на карту памяти в формате, который понимает прошивка vCodex:

- файл скачивается с device-scoped эндпоинта `/api/v1/crosspoint/reading/vcodex`
  по токену плагина и записывается дважды — в `/.crosspoint/reading_stats.json`
  (единственный путь, который сканирует импорт vCodex) и в
  `/exports/stats_exported` (путь страницы импорта CPR/Mimee-семейства);
- если файл уже лежит, первое нажатие только предупреждает:
  **«Файл уже есть: … Нажмите ещё раз, чтобы перезаписать»**;
- импорт в прошивке: **Настройки → Приложения → Reading Stats → Import
  Statistics → источник vCodex → выбрать его ещё раз для подтверждения**;
- страница сверяет возможности прошивки через `/api/status`
  (`pluginCapabilities`) и показывает их: если у прошивки нет страницы импорта,
  она честно сообщает об этом вместо выдуманной инструкции.

Импорт аддитивный и одноразовый по каждой книге: сессии, суммы и даты чтения
переносятся один раз, повторная выгрузка уже импортированные книги не
пересчитает (прошивка хранит квитанции). Счётчиков перелистываний в облаке нет,
поэтому они не выдумываются. Если файл не записался, страница покажет, сколько
файлов сохранилось и какой путь подвёл.

## Веб-настройки плагина

Кроме экрана ридера у плагина есть страница в web-интерфейсе устройства
(**Settings → YBX**):

- **KOReader Sync одной кнопкой** — включает встроенную синхронизацию позиции
  с device-scoped KOSync YBX (`/api/v1/crosspoint/kosync`) без ручного ввода
  сервера и пароля;
- **Проверить обновление / Обновить** — страница проверяет релиз сама при
  открытии и показывает баннер; кнопка берёт сборку из релизов YBX
  (`/crosspoint-plugin/latest.json`), без Plugin Hub;
- **Выгрузить статистику (vCodex)** — облачная статистика чтения на карту
  памяти в двух путях для импорта прошивкой vCodex;
- **Отвязать устройство** — стирает ключ плагина на карте и выключает KOSync,
  если он указывал на YBX.

## Настройка KOSync (опционально)

Для синхронизации позиции чтения во время чтения:
1. Перейдите в **Настройки → Подключения → KOReader Sync**.
2. Включите синхронизацию.
3. Сервер: `https://my.ybx.app/kosync/`
4. Логин и пароль: идентификатор и ключ вашего ридера (доступны в личном кабинете).
5. Включите опцию **Отправлять метаданные книг** (*Send book metadata*). Метаданные из файла `<книга>.meta.json` будут автоматически привязываться к прогрессу.

## Ответы сервера и восстановление

Все запросы каталога, поиска, EPUB и событий используют `Authorization: Bearer {token}`; токен не передаётся в URL. Маршруты: `POST /auth/device`, `POST /auth/token`, `GET /catalog`, `GET /catalog/search`, `GET /books/{id}/download`, `POST /events` под `https://my.ybx.app/api/v1/crosspoint`.

| Ответ каталога | Экран и действие |
| --- | --- |
| 401 (неизвестный, истёкший или отозванный токен); 403 также обрабатывается прошивкой | Экран входа `NO_TOKEN`; подтвердите вход для новой QR-привязки. Старый файл токена сохраняется. |
| 409 `books_consent_required` (поиск, EPUB) | Общая ошибка; подключите Яндекс Книги в кабинете, токен сохранён. Полки вместо ошибки дают строку «Подключите Яндекс Книги в кабинете YBX» с шагами. |
| 404 + `X-YBX-Device-Removed: true` | Ридер удалён в кабинете; общая ошибка загрузки. Локальные книги и токен сохраняются, автоматической QR-привязки нет. Для повторного подключения удалите только `token.json` этого плагина на SD и откройте плагин. |
| Обычный 404 | Нет книги или плагин отключён на сервере; маркера удаления нет. |
| 429 + `Retry-After: 60` | Общая ошибка; подождите минуту и повторите. Прошивка не использует `Retry-After` автоматически. |
| 502 | Библиотека временно недоступна; повторите позже. |

При загрузке EPUB ошибки HTTP показываются как ошибка загрузки, без автоматической device-code авторизации; токен сохраняется. События с любым ответом вне 2xx остаются в очереди.

Лимиты на 60 секунд (токен/аккаунт): каталог и поиск 180/600, EPUB 20/60, события 120/360. Одновременно допускается 2 загрузки на аккаунт и 8 всего; превышение возвращает 429.

При опросе авторизации `authorization_pending` продолжает ожидание, `slow_down` добавляет 5 секунд к интервалу; `expired_token` и `access_denied` показывают ошибку входа. Неизвестные ошибки (включая `invalid_grant`) ожидают до конца срока кода. Ответ токена содержит `expires_in=7776000`, но прошивка сохраняет только `access_token`, без refresh token.

В проверенной прошивке TLS не проверяет сертификат сервера (`setInsecure()`). Используйте доверенную сеть, защищайте SD-карту и удаляйте потерянный ридер в кабинете. Скопированный токен даёт доступ до истечения срока или отзыва.

Проверка: [tests/VALIDATION.md](tests/VALIDATION.md). Контракт: [CROSSPOINT_PLUGIN_API.md](../../../../docs/CROSSPOINT_PLUGIN_API.md).

## Исправления 1.4.1

График показывает минуты без обязательного `sources`, неделю Пн–Вс через границу
месяца и прочерк для неизвестных значений; WebUI наследует тему CrossPoint.
Сервер исправляет полку «Читаю» для начатых pending-книг и дополняет карточки
прогрессом, серией и библиографией. KOSync предупреждает о замене адреса, логина
и параметров; отмена сохраняет настройки, уже настроенный YBX не перезаписывается.

Вложенные папки, обложки JSON-карточек и меню действий требуют доработки
прошивки. Полное дерево провайдеров, полок и серий доступно через OPDS.

## WB Books in 1.5.0

Connect WB Books in the YBX account cabinet, then open the WB Books catalog
in the plugin. Only EPUB entries from that account's library are offered.
The search covers Yandex Books and a connected WB library. Subscription
access is enforced by WB when YBX requests the file; appearing in the library
does not guarantee that every title is downloadable.

WB credentials remain on the server. CrossPoint receives the EPUB stream
through YBX, with the configured server download-size limit. Expired WB
authorization is refreshed once using the stored refresh token. If refresh
fails, reconnect WB in the account cabinet. The firmware displays a generic
fetch error for that response and keeps the plugin token.

Book IDs beginning with `wb--` identify WB entries in sidecar metadata. New
downloads use `{id} - {title}.epub` to prevent books with the same title from
replacing one another. Existing files are not renamed. Metadata uses provider
`ybx`; the book ID identifies the source. Old Yandex sidecars remain valid.

WB and purchased LitRes EPUBs are also available in OPDS, with signed links.
The library scan is bounded to 1,000 entries; larger libraries return an error.
Physical-reader verification remains a separate check.

## Обновления 1.6.x

Плагин сообщает о новой версии сам: полка каталога начинается с «Доступна
YBX <версия>», карточка сна добавляет строку об обновлении, веб-настройки
показывают баннер у кнопки «Обновить». Все запросы несут версию в `?v=`.
