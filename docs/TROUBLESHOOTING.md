# Решение проблем

[← На главную](../README.md) · [Установка](INSTALL.md) · [Статус](STATUS.md)

### Позиция уходит с ридера в Яндекс, но не возвращается

Проверьте **не только источник книг**, но и именно настройки KOSync. Встроенное зеркало CrossPoint Sync может пересылать прогресс в YBX, не запрашивая обратную позицию. Откройте веб-панель YBX через `http://crosspoint.local/plugins`, настройте KOSync, проверьте статус авторизации и выполните `Sync Progress` на ридере. Серверный `200` на отправке не означает успешного применения удалённой позиции.

### На CrossPoint 2.0 нет раздела YBX в настройках

Панель плагина открывается **в браузере**, а не обязательно отдельным пунктом системного меню. Включите Wi-Fi, File Transfer, затем откройте `http://IP-ридера/plugins` с устройства в той же сети. Проверить наличие `plugin.js` рядом с `device.json` в папке YBX.

### После обновления пропал вход

Если установщик заменил всю папку `ybx`, файл `token.json` мог исчезнуть. Повторите привязку по QR. Пожалуйста, не публикуйте токен или пароль в issue.

### Статистика YBX заменила мои обои

Начиная с 1.6.12 статистика добровольная. В веб-панели отключите её. Если в `/sleep.bmp` осталась старая карточка без метки YBX, используйте ручную очистку с подтверждением и резервной копией. Не удаляйте файл, не убедившись, что это действительно карточка YBX.

### После обновления опять нужно включать статистику

1.6.12 сохраняет выбранный режим при обычном обновлении из веб-панели. При полной замене всех данных плагина через сторонний установщик файл `sleep-preference.json` может потеряться. Его сохранение зависит от способа обновления.

### InkHome / vCodex: нужно ли импортировать статистику YBX?

**Пока нет, если на устройстве уже есть статистика чтения.** В InkHome локальная статистика хранится в `/.crosspoint/reading_stats.json`, а импорт замещает её. Экспорт YBX 1.6.12 может перезаписать тот же файл после подтверждения. Сохраните независимую копию, не подтверждайте перезапись, дождитесь безопасного обмена с объединением записей.

### Какие данные приложить к issue?

Модель ридера, точная версия прошивки, версия плагина (например, 1.6.12), путь установки, последовательность действий, ожидаемый и фактический результат, скриншот. **Не прикладывайте токены, QR-привязки и пароли.**
