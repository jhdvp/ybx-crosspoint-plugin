# Установка YBX CrossPoint Plugin

[← На главную](../README.md) · [Последний релиз](https://github.com/jhdvp/ybx-crosspoint-plugin/releases/latest)

## Установка

**Рекомендуемый способ:** на ридере открыть `Home → Plugins → Plugin Hub → Community Plugins → YBX` и установить плагин, если он присутствует в каталоге вашей сборки.

**ZIP:** скачать `ybx-plugin-1.6.12.zip` из [GitHub Releases](https://github.com/jhdvp/ybx-crosspoint-plugin/releases/latest), распаковать директорию `ybx/` на карту MicroSD в `/plugins/ybx/` либо `/.crosspoint/plugins/ybx/` согласно версии прошивки. Не допускать вложенного `ybx/ybx`.

Включите плагины: `Settings → Connectivity → Plugins → Enabled` (названия меню могут немного отличаться).

## Первая авторизация

Откройте `Home → Plugins → YBX`. На ридере появится QR-код и код устройства. Отсканируйте QR телефоном, войдите в [YBX](https://my.ybx.app), подтвердите привязку и подключите необходимые источники книг.

Основной токен плагина `cp_` даёт доступ к каталогу и связанным функциям. Он **не является** паролем Яндекс ID или KOSync. Не публикуйте его.

## Веб-настройки на CrossPoint 2.0

1. Подключите ридер к Wi-Fi и включите `File Transfer`.
2. С телефона или компьютера в той же сети откройте `http://crosspoint.local/plugins` или `http://IP-ридера/plugins`.
3. Выберите **YBX**. Здесь находятся статистика, настройки сна, KOSync, проверка обновлений и отвязка.

## Обратная синхронизация

В веб-панели YBX нажмите **«Настроить KOSync»**. Плагин устанавливает `http://sync.ybx.app/api/v1/crosspoint/kosync` и отдельный ограниченный ключ; сервер не требует HTTPS для этой категории ключей. HTTP **не шифрует соединение**. Если ридер поддерживает надёжный HTTPS, предпочтителен защищённый маршрут, если он поддерживается выбранным режимом.

Если KOSync уже настроен вручную под другой сервер, внимательно прочитайте запрос на замену настроек. Не удаляйте предыдущие учётные данные.

**Контроль:** поменяйте позицию в Яндекс Книгах, откройте соответствующий EPUB на ридере, выполните `Sync Progress` и проверьте, предложена ли удалённая позиция. Доступность этого действия зависит от firmware. При совпадающем названии, но другом содержимом EPUB сопоставление может не сработать.

## Экран сна

В веб-панели YBX кнопкой включите статистику. На стандартном CrossPoint используется режим `Custom` и файл `/sleep.bmp`. Перед заменой пользовательского изображения плагин запрашивает подтверждение и делает копию. При выключении возвращает сохранённое изображение, когда это возможно.

На форках с собственными режимами сна (например, InkHome) **не включайте эту опцию без отдельной проверки совместимости**.

## Обновления

Обновление через веб-панель сохраняет необходимые настройки и выбранный режим статистики сна. Некоторые установщики Plugin Hub полностью заменяют папку плагина: `token.json` и локальные настройки могут потеряться. В этом случае выполните QR-привязку повторно. Для диагностики см. [FAQ](TROUBLESHOOTING.md).
